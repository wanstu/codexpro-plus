# Phase 3 Plan 01 — 托盘与两级自启

## Objective

实现 Windows 托盘常驻、关闭隐藏、管理器开机自启和 Workspace 自动拉起。

## Tasks

### Task 1 — TrayManager
- 增加 `github.com/gogpu/systray` 依赖。
- 使用现有 PNG 作为托盘图标。
- 左键显示 Wails 主窗口。
- 右键菜单：打开主面板 / 退出。
- 显式退出调用 Wails Quit；shutdown 清理 tray。

### Task 2 — Wails lifecycle / manager single-instance
- Windows 入口增加单实例锁；已有 codexprov4 运行时不创建第二个 App/ProcessManager。
- 普通重复启动通知已有实例恢复/显示主窗口；`--autostart` 重复启动静默退出，不弹窗。
- `HideWindowOnClose=true`。
- 注册 `OnDomReady` / `OnShutdown`。
- `--autostart` 启动参数对应 `StartHidden=true`。
- shutdown 停止全部受管 core 实例。

### Task 3 — Manager auto-start
- 新建 Windows registry helper。
- `GetManagerAutoStart()`。
- `SetManagerAutoStart(enabled)`。
- UI 增加管理器开机自启开关与说明。

### Task 4 — Workspace auto-start
- App startup 后读取 Workspace 配置。
- 逐个启动 `auto_start=true` Workspace。
- 单个失败只记录 runtime error，不阻断后续项目。
- 更新 Phase 1 表单说明，`随管理器启动` 从“仅保存偏好”变为真实功能。

### Task 5 — Verification
- `go mod tidy`
- `go test ./...`
- `wails build`
- 人工验证托盘左/右键、窗口关闭隐藏、退出、manager autostart 注册、workspace autostart。
